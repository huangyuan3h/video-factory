**结论速览（一屏 6 句）：**

1. **Go（条件通过）：** 头条是三站里变现门槛最低的——0 粉 + 实名 + 信用分 100 即可开通文章/视频/微头条创作收益，算法不依赖粉丝，适合我们这种“长图文 + 横屏中视频”存货直接复用。
2. **资质是最大分水岭：** 纯投资者教育回测（无个股代码、无买卖点、无收益承诺）**无财经资质也可发**，但【官方+社区】无资质发财经专业内容会被限在粉丝池/仅粉丝推荐；要做“股票买卖指导、投资指南”级内容则必须考证券从业 + 证券公司在职证明，个人短期拿不到。
3. **首发冲突无解，必须排期：** 头条“首发激励”要求 72 小时全网独家，YouTube/B 站/知乎已发的同一内容**绝不能再勾首发**（否则扣 5 分 + 扣补贴），只能勾“原创 + 投放广告”拿基础分成；想吃最高 5 倍首发补贴就必须头条先发 72 小时，与现有 lead 顺序矛盾——建议放弃首发补贴，保全网节奏。
4. **形态打法 = 文章（主）+ 横屏视频（主）+ 微头条（辅）：** 知乎 1500–2500 字长文可几乎原样搬到头条文章，1920x1080 视频可直接发头条视频/西瓜视频，微头条只做预告和搜索钩子；不要只发独立小视频（<1 分钟无收益）。
5. **自动化无官方长内容 API：** 抖音开放平台官方 API 只支持 <1 分钟小视频直传，不支持文章/微头条/长视频，个人走不通；现实路径是复用 Douyin/Xiaohongshu 模式的 **Playwright + 扫码登录态 + 先存草稿人工审**，已有开源 `toutiao-auto` / `toutiao-publisher-skill` 验证可行，HTTP 直调 `POST /mp/agw/article/wtt` 只稳在微头条，文章直调曾报 7050。
6. **早期别指望赚钱：** 0 粉即有分成但单价看完读/互动/广告位，【社区经验】普通图文千次约几元到几十元，财经略高但内卷；前 1–2 个月现实期望是每月几十到几百元 + 搜索长尾，真正的钱在万粉后的付费专栏/星图/带货，而那需要财经资质。

## 1. 账号：注册/实名/资质/认证/新号限制

### 1.1 注册与实名【官方明确规定】

- 入口：`https://mp.toutiao.com/`（头条号后台），App 端今日头条 → 我的 → 创作中心。来源：https://mp.toutiao.com/ ，https://baike.toutiao.com/detail/2789/20588 （2026-04-14 更新）。
- 5 种主体：个人 / 企业 / 国家机构 / 新闻媒体 / 其他组织。个人适合垂直专家、达人、非公司小团队；**一个身份证最多 1 个个人头条号**，一个营业执照最多 2 个机构号，已注册个人号的身份证仍可再注册机构号。
- 个人注册材料：头像 + 昵称 + 简介即可提交，然后在今日头条 App 做作者实名认证（身份证正反面 + 人脸），认证通过即审核通过。机构号另需营业执照/组织机构代码证、运营人姓名/身份证号/手持照、联系邮箱、账号确认书；新闻媒体号另需《互联网新闻信息服务许可证》等 9 类媒体资质之一 + 对公账户打 0.01 元验证（户名北京抖音信息服务有限公司）。
- 账号名红线（审核规范）：禁“今日/头条”字样（冒充官方），禁“优质/原创/加油包”等平台身份词，经济/教育/医疗/司法/媒体领域无资质不得用职业专有名词（如 `XX医生` 需材料，财经同理，见 §1.2）。

### 1.2 财经/证券资质：纯回测教育要不要考证？

**【官方明确规定】要区分“专业性强”与“一般科普”：**

- 今日头条社区规范 + 内容审核规范原话：`未申请财经类专业资质认证的个人和机构，不得发布股票买卖指导、投资指南等财经领域专业性强的内容`；`未取得互联网新闻信息服务许可，不得发布时政类新闻信息`。来源：https://baike.toutiao.com/ （社区规范页，2025-12-01 更新），https://mp.toutiao.com/docs/dianshang/4268/31578 ，星图版 https://www.xingtu.cn/help-center/mcn/109214 （2026-06-11）。
- 财经/健康资质证明页（2026-08-10 更新）：https://baike.toutiao.com/detail/242/340/0
  - 股票类个人号需：证券从业考试成绩单（《证券市场基本法律法规》+《金融市场基础知识》均 ≥60，或《法规》+《证券投资基金基础知识》均 ≥60）或中证协从业登记信息，** plus 证券公司 30 天内开具的在职/经纪关系证明（含姓名/身份证/入职时间/职务/公章）**。机构号需《经营证券期货业务许可证》+ 营业执照 + 30 天内机构证明。
  - 基金/期货/保险各有对应口径（基金需中基协注册信息 + 公司销售/投顾/在职证明；期货需中期协登记 + 投资咨询资格号 + 期货公司在职证明）。无一例外都要“考试 + 在职”双绑，纯散户考过也拿不到。
- **对我们的判断：**
  - 「什么指标不赚钱」只讲历史回测、不点名个股代码、不给买卖价位、不承诺收益 + 全篇免责，属于“投资者教育/科普”，**可以无资质发布**（对标抖音/视频号公约鼓励的“客观中立科普 + 风险提示”，见 B 站篇 §4.1 引用）。
  - 但无资质的代价【官方 + 社区经验】：一是只能在资质许可范围外发，一旦被判“股票点评/行业分析等专业性强”就会被处理（限流/下架/扣分）；二是【社区经验，多篇创作者教程一致，但官方未写明比例】无资质发财经内容**仅向粉丝推荐、不进公域**（抖音扫码教程原话：“没有资质的作者发布健康财经内容将仅向粉丝推荐”）。本报告标记为**部分验证**：官方只写“将根据规定处理”，“仅粉丝可见”是社区口径，实测前不要承诺流量。
  - 笔名/简介千万别写“基金经理/投顾/证券公司/分析师”等词（无资质写了即违规，见账号名规范 + 抖音/视频号公约类比）。

### 1.3 领域/兴趣/职业认证有什么用

- 头条认证体系：个人认证 / 职业认证 / 兴趣认证 / 企业认证 / 机构认证（百科左导航）。【官方】职业认证需资质证照 + 在职三一致（人 = 证 = 司），兴趣认证（财经/科技/读书等）靠持续发文 + 审核，对应“黄 V”外显。
- 好处【官方】：认证号在搜索、首发维权、全网维权签约、星图接单上有加权；财经资质 + 黄 V 是星图接单的前置（见 §4）。坏处：认证后人设锁死，财经号发娱乐会被判“人设不一致”取消资质（资质管理规范原话）。
- 建议：先不做任何职业认证，用兴趣认证（财经/科技/读书）冷启动；等粉丝过万且确定考证/挂靠路线再做职业认证。

### 1.4 新号限制：新手期、每日 caps、信用分

- 新手期：【社区经验】旧“新手期转正”机制已取消，现为**创作者计划 + 信用分 100 分制**。官方入口：头条号后台 → 成长指南 → 创作权益，或 App → 我的 → 创作中心 → 创作权益，加入计划即开基础权益。来源：https://mp.toutiao.com/docs/baike/2789/37620 （2025-03-27）。
- 每日发文上限：【官方】只写“对各体裁设有每日发文数量阈值，超过后仅推荐给粉丝，具体数量因账号而异”（`naizai.cn/tool/toutiaohao` 转述官方 FAQ）。【社区经验，未验证】：微头条 50 篇/天；文章 + 微头条 + 问答 + 视频合计 50 条/天；新号单日文章 >5 篇会触发严审推荐骤降（https://www.toutiao.com/article/7486893466284098082 ，https://www.xinmeijiatech.com/a/94.html 2026-06-24）。**以创作中心实时页为准，本报告不承诺数字**，运营上按 §6 节奏（每周 2–3 篇）根本碰不到上限。
- 信用分：【官方明确规定】满分/初始 100，违规扣 5–70，扣到 0 封禁（https://baike.toutiao.com/detail/236/470/0 2026-06-17）。
  - 100 分：可使用 + 申请新权益；61–99：可用已有 + 可申请新；0–60：全部权益关闭，需 10 天无违规 +10 分爬回 60 以上重申；≤30：联动禁言 7 天。
  - 与我们最相关的扣分：违规声明首发 5 分；标题党/违规推广/旧闻翻炒/抄袭 10–20 分；荐股/医疗营销/谣言/严重标题党 70 分。首次非恶意扣分可答题即时恢复（违规声明首发、违反平台行为规范除外）。

## 2. 内容规则（财经重点）

### 2.1 禁止清单：荐股、收益承诺、引流、水印外链

**【官方明确规定】**（社区规范 + 电商/星图审核规范）：

- 无资质禁发股票买卖指导/投资指南；无论有无资质**均禁高风险金融产品营销**（股票/期货/贵金属/原油/基金/债券/P2P/数字货币/期权/外汇，星图原话）。
- 禁违法推荐（明示暗示买卖时机/价格/预测走势）、禁承诺收益（保本/稳赚/翻倍）、禁恶意唱衰/歪曲政策、禁伪造背书（内部消息/监管背书）、禁虚拟币/NFT、禁站外引流（展示联系方式、领资料诱饵、私信加微信、谐音字变相建联）。此 8 类与抖音公约（2025-12-16）、视频号公约（2026-04-01 生效）同构，头条只会更严（长图文长尾责任更重）。来源：§1.2 链接 + https://finance.sina.com.cn/tech/digi/2025-12-16/doc-inhaymzi3266679.shtml ，https://www.nbd.com.cn/articles/2026-03-27/4311344.html 。
- 禁其他平台水印/名字：抖音开放平台头条发布方案原话“带品牌 logo 或品牌水印的视频，会命中审核逻辑，有大概率降权/下架/封号，第三方须自行处理”（https://open.douyin.com/platform/resource/docs/ability/content-management/toutiao-publish-solution）。**实操：成片片头片尾禁 YouTube/B 站水印和口播“关注我的 B 站/YouTube”，封面禁二维码，简介禁外链/微信号**，主页简介最多写“全网同名躺平的老黄”文字（不挂链接）。
- 禁标题党（震惊/惊爆/传疯 + 话说一半 + 封面党），禁抄袭洗稿（见 §2.3）。

**必须做（财经每篇/每集）：** 不点名个股/基金代码、不给价位、不预测“必涨/看到 XX 点”、不用暗号；口播 + 正文双位置免责模板：`本内容为投资者教育，不构成投资建议。历史数据仅供参考，过往业绩不代表未来表现。投资有风险，入市需谨慎。`；收益对比图必须标“历史数据仅供参考”；引用财报/央行来源用文字名（不贴站外 URL）；不卖课、不建收费圈、不留微信/QQ。

### 2.2 AI 生成声明【官方明确规定，必须做】

- 《人工智能生成合成内容标识办法》（国信办通字〔2025〕2 号，2025-03-07 发，2025-09-01 施行）：https://www.gov.cn/zhengce/zhengceku/202503/content_7014286.htm 。文本/音频/图片/视频/虚拟场景要加显式标识（可感知）+ 隐式标识（文件元数据 AIGC）；用户发布 AI 内容须**主动声明并用平台标识功能**，不得删改伪造。
- 头条侧：2025-09 起上线 AI 标识功能 + “清朗·整治 AI 滥用”专项；【社区经验】创作者实测“不标注限流、扣分还可能封号”（https://www.toutiao.com/article/7546028617956917799）。我们全链路 AI（LLM 脚本 + Edge-TTS 配音）**每篇必做三件套**：发布页勾选 AI 生成声明 + 正文首尾加一句 `本文/本视频文案/配音由 AI 辅助生成，已按平台规范声明。` + 视频起始画面显著提示。

### 2.3 原创 vs 首发：已发 YouTube/B 站/知乎怎么办（核心坑）

这是头条与 B 站/知乎差异最大的地方，**【官方明确规定】**（首发激励计划页，2026-05-25 更新）：https://baike.toutiao.com/detail/242/566/0

- 原创：自研图表 + 原创解说 + 合规二创即算原创，声明原创后图文阅读量按 3 倍计入作者系数（2022 分成改革口径，见 https://edit.newrank.cn/detail.html?uuid=A34426200C4ACD5381EE8F125F8DAEBD）。违规用原创（抄袭/洗稿/搬运）即扣分。
- 首发（单篇制，2025-08-28 升级）：声明首发需同时满足**原创 + 首发在头条 + 72 小时内未在其他平台发布 + 正文 >100 字 + 五大质量标准**；符合激励条件最高可获 **5 倍额外补贴** + 全网维权服务；非首发仅基础分成；违规内容无分成无补贴。
- **冲突规则（逐字）：** `内容在头条发布前在其他平台发布过，或在头条发布后 72 小时内在其他平台发布，认定为非首发`；`同矩阵/同 MCN/同作者多次发布相同文章，只有一篇可声明首发`；`开启账号内容同步授权导致自动同步到其他平台同时发布，不符合首发`。违规声明首发每篇扣 5 分（30 天上限 50 分）+ 扣除首发补贴，频繁发低质首发冻结 14 天，两次永久关闭首发功能。
- **对我们的结论：** 现有流程 YouTube lead → B 站/知乎同步，天然与“头条首发 72 小时独家”互斥。**不要为吃补贴打乱全网节奏**：头条侧每篇只勾“原创 + 投放广告”，不勾首发，拿基础分成 + 搜索长尾。若某篇想冲首发补贴，必须走特殊排期（头条先发 72 小时，见 §6），一年最多试 1–2 篇。
- 搬运风险：头条消重 + 全网维权签约 + 洗稿打击极严（2025-09 永久封 443 个侵权洗稿号，见 https://m.thepaper.cn/wifiKey_detail.jsp?contid=2019701 ；2026 上半年处置刷量垃圾号 85.7 万，拦截虚假刷量 1900 亿次）。同一成片多平台发**不算搬运**（著作权人是自己），但直接复制他人回答/研报、影视原片混剪、去水印即判抄袭扣 10–20 分 + 限流 7 天黑盒（创作者自述 https://www.toutiao.com/article/7200150216425734708）。

### 2.4 时政新闻：个人建议不发（与 B 站/知乎一致）

【官方】无《互联网新闻信息服务许可证》不得发布时政类新闻信息（含政治/经济/军事/外交报道评论 + 突发）。个人不可能取得（只发境内法人 + 新闻单位）。财经里的宏观政策解读可以做，**选举/冲突/制裁/领导人活动等时政不做**；若试发只转述新华社/央视已发 + 注明来源名 + 不预测不站队，做好“发 10 删 9”预期。

## 3. 体裁：视频 / 文章 / 微头条，怎么复用

### 3.1 规格【官方 + 社区经验分区标注】

| 体裁 | 官方口径 | 建议（沿用现有产出） |

### 3.2 哪个最适合我们 + 复用矩阵

- **指标回测 → 文章 + 视频双主力**：文章吃搜索（`MACD 有用吗`类长尾，头条搜索占比 2026 已到 26%【社区经验】），视频吃推荐；每集产出 `output.mp4 + cover + meta.json + zhihu.md`，头条文章 = `zhihu.md` 改标题 + 首段 200 字重写（防消重）+ 封面重裁 + 删站外链接 + 加免责/AI 声明，10 分钟可发。
- **书摘 → 文章主力**：头条读书搜索长尾深，专栏连载 + 付费专栏后路，视频为辅。
- **财经/科技新闻 → 微头条/问答**：时效短不值得开专栏；科技可发视频，财经只发无个股宏观。
- **政治/时政 → 三站都不发**。

### 3.3 头条视频会同步到抖音/西瓜吗

- 会，但**默认不同步，需手动开，且开了就丢首发**。路径：头条号后台/西瓜创作平台发中视频（1–30 分钟横屏 PGC）时勾选“同步到抖音/西瓜”，或抖音发中视频同步到头条/西瓜（中视频伙伴计划 2021–2024，现升级为抖音创作者伙伴计划 + 头条视频创作收益，见 https://zh.wikipedia.org/zh-cn/西瓜视频）。
- 警告：独家视频违约扣 20 分（信用分细则 §3.2.4）；首发规则明确同步即非首发。所以**同步开关默认关**，除非该篇已放弃首发补贴。横竖差异大（抖音竖 9:16 vs 头条/西瓜横 16:9）也不要强同步，竖版转横版黑边会被判低质。

## 4. 钱：门槛、公式、早期期望、其他变现

### 4.1 开通门槛【官方明确规定】

- 基础权益（0 粉可申）：文章创作收益、视频创作收益、微头条创作收益、热点图库。路径 App → 我的 → 创作中心 → 创作权益 → 立即加入创作者计划。来源：https://mp.toutiao.com/docs/baike/2789/37620 。
- 前提：完成实名 + 信用分 100（任一扣分即卡首发/原创/新权益）；国家机构/其他组织号无创作收益。百粉开问答/微头条全量，千粉开图文/视频赞赏，万粉开付费专栏/头条小店/星图接单（星图另需信用 ≥60 + 财经/健康资质，见 https://www.xingtu.cn/help-center/author/109251）。
- 发布时必须勾选：文章/视频编辑页 `投放广告赚收益` + `声明原创`（不勾几乎无收益，见 https://baike.toutiao.com/detail/192/198/0，抖音教程 https://www.douyin.com/shipin/7303974561765132324）。

### 4.2 分成公式与早期期望

- 【官方】`收益是阅读量 + 广告主出价 + 内容质量的综合结果，相同阅读收益不固定`；首发优质最高 5 倍补贴（见 §2.3）。
- 【社区经验，不承诺】公式：`总收益 = 千次单价 × 互动系数（收藏>转发>长评论>点赞）× 获利阅读（看完/停留/看到广告才算）+ 首发补贴 + 活动奖金`；高单价赛道（社保/医保/理财/健康/职场/政策解读）千次 30–60 元，中 10–25，低（八卦/碎碎念）3–10（见 https://840f.com/news/xinmeitiyunying/1987）。财经回测属中高单价但竞争大。
- **现实期望（标记未验证）：** 0 粉新号前 10 篇平均阅读几百到几千，单篇几毛到几元；周更 2–3 篇第一个月总收益通常几十元；跑顺 3 个月 + 出 1–2 篇爆款（10 万+）才可能月入几百到上千。不要按“首发 3 倍保底”做账（官方 Q7 已明确无保底，按质量 1–5 倍浮动）。

### 4.3 其他变现

赞赏（千粉）、付费专栏（万粉，书摘最适合，低价 9.9 引流 → 高价 199 课）、内容带货/商品卡（佣金 15–30%，但带货占比 >30% 会被标营销号降权）、头条小店、巨量星图商单（万粉 + 信用 60 + 财经资质，财经号无资质接不了单）。本书摘/回测号 6 个月内主靠广告分成 + 专栏，星图是远期。

## 5. 自动化：官方 API vs 浏览器自动化

### 5.1 官方开放 API：个人走不通长内容【官方明确规定】

- 唯一对头条的官方写入是抖音开放平台 `头条内容发布接入方案`：`POST /toutiao/video/create/`（scope `toutiao.video.create`），默认开通给审核通过的应用，支持移动/网站/硬件应用（https://open.douyin.com/platform/resource/docs/ability/content-management/toutiao-publish-solution ，https://open.douyin.com/platform/resource/docs/openapi/video-management/toutiao/create-video/publish-video）。
- 硬伤：**仅小视频，不支持文章/微头条/长视频**；限制 16:9 720p+、mp4/webm、≤300M、<1 分钟；审核逻辑与端内一致；建应用需企业级审核 + 回查 + 场景限定（代替用户发抖音接口更只限党政/媒体，见 https://developer.open-douyin.com/capacity-center-page/capacity-detail/7224121299067469881）。我们 4–8 分钟视频 + 2000 字文章**完全用不上**。
- 结论：官方 API 对本项目不可用（与 B 站/知乎同结论）。不要为此注册公司。

### 5.2 浏览器自动化 / HTTP 逆向：唯一现实路径【社区经验 + 开源验证】

| 路径 | 状态 | 原理 | 评价 |
|---|---|---|---|
| `lastdanger/toutiao-auto` https://github.com/lastdanger/toutiao-auto | 可用（Playwright，draft/publish 双模式） | 抖音 App 扫码登录 → cookie 持久化 → 富文本填标题/正文/封面/正文图 → 存草稿或直发，支持 markdown/html，失败重试 + 截图 | **推荐对标**：与我们 `douyin.py/xiaohongshu.py` 同构，可直接抄 `browser.py/auth.py/publisher.py/retry.py` 结构 |
| `zhuzhuppx/toutiao-publisher-skill` https://github.com/zhuzhuppx/toutiao-publisher-skill/blob/main/SKILL.md | 微头条稳，文章不稳（2026-06-30 验证） | HTTP 直调 `POST https://mp.toutiao.com/mp/agw/article/wtt`（微头条，需 `X-CSRFToken: passport_csrf_token` + cookie `sessionid/sid_tt`），`image_list` 必须用 `image_uri` 短格式；文章 `POST /mp/agw/article/publish` 7 种姿势均 `7050 保存失败`（疑 A/B 灰度 `hit_new_origin_gray` 或缺 `title_id` 签名） | 微头条可用 API，**文章/视频必须走 Playwright 草稿**，不要硬调文章 API |
| 通用 Playwright 模式（掘金/CSDN/小红书多平台实录） | 可用但需维护选择器 | `storageState.json` 复用 + 真 Chrome CDP 9222 + 人类化延迟，知乎/B 站同理 | 头条反爬弱于知乎，但高频/多号同 IP/刷量必封（见下） |

- 登录：主流**抖音 App 扫码**（`toutiao-auto` 默认），备选手机号 + 短信验证码；无密码直登。Cookie 关键字段 `sessionid/sid_tt + passport_csrf_token (+ _xsrf)`，有效期数天到数周，过期报 `100005 获取用户信息失败` 需重扫。
- 验证码/风控：新号/异地/无头/高频会弹滑块/短信；2026 上半年头条处置刷量垃圾号 85.7 万、拦截刷量 1900 亿次、清互粉 1117 万、下架水军评论 1623 万（https://mp.toutiao.com 安全中心公告转述 http://xz.caixinfo.net/news/909.html）。**低风险**：单号单 IP、每天 ≤1–2 更、间隔 6h+、先草稿人工审、模拟正常间隔（上传→填标题/封面/勾原创广告→预览→发布隔数分钟）；**高风险**：日更 5–10、机器人无间隔群发、多号同 IP互粉、标题党、站外引流。
- 推荐 pacing：冷启动前 2 周每天 ≤1 文章 + ≤1 视频 + ≤2 微头条，白天 7–9/12–13/19–22 点发；稳定后每周 2–3 文章 + 1–2 视频 + 3–5 微头条。

**推荐方案：** v1 半自动（worker 只产 `toutiao.md + output.mp4 + cover_1024x678 + meta.json`，人工一键发，保留 `PUBLISH_REQUIRE_REVIEW=1`）；v2 再接 Playwright 发布器（复用 Douyin/Xiaohongshu publisher，draft 默认，publish 需人工确认），微头条可先试点 HTTP 直调。

## 6. 推荐：go/no-go、形态、节奏、排期、工程量、分步计划

### 6.1 Go / No-go

- **Go（条件）：** 文章 + 横屏视频双发，微头条辅助；财经只做无个股教育，政治不做；放弃首发补贴保全网节奏。
- No-go：不单独为头条重拍竖屏、不考证前碰个股推荐/收费圈、不买粉不群发、不开自动同步到抖音。

### 6.2 形态与节奏

| 系列 | 头条形态 | 节奏 | 备注 |
|---|---|---|---|
| 指标回测 | 文章（主）+ 视频（主） | 每周 1 篇文章 + 1 视频（同题） | 标题含指标名 + 疑问词，话题 3–5 个细分 |
| 书摘 | 文章（主，专栏连载） | 每周 1 篇 | 书名长尾词 + 出版社 + 原创解读声明 |
| 科技新闻 | 微头条/问答 + 视频 | 有料才发，每周 ≤2 | 官方 press kit 图，署名 |
| 财经新闻（宏观无个股） | 微头条/问答 | 每周 ≤2 | 加 `事实截至 XX` + 免责 |
| 政治时政 | 不发 | — | — |

### 6.3 全网 lockstep（解决首发冲突）

`YouTube（lead, 英文+中文）→ B 站（+2h，审核 2–6h）→ 知乎（+1 天，回答+文章+视频嵌入）→ 头条（+72h 后，只勾原创+广告，不勾首发）`。头条发布时间 = 知乎发布时间 +72h（用定时/人工卡点）。若某篇要冲头条首发补贴，单独走 `头条先发 → 72h 后再发 B 站/知乎/YouTube`，一年 ≤2 篇，且提前在标题页标注。

### 6.4 工程量估计

- v1 半自动（无代码）：0 天，worker 已有 `zhihu.md + output.mp4`，人工按 §6.5 清单发，封面多裁一版 1024x678。
- v2 Playwright 发布器：**2–4 天**（复用 `douyin.py/xiaohongshu.py`：cookie 管理 + 草稿/发布双模式 + 重试截图 + 回读 URL；参考 `toutiao-auto` 的 selectors；微头条 HTTP 直调半天可试点）。维护成本：头条一改版跟一次选择器，约 0.5 天/次。

### 6.5 分步计划（含 Yuan 必须手动做的）

1. Yuan 手动：下正版今日头条 App（非极速版），手机号注册 → 头像/昵称 `躺平的老黄`/简介（不写基金经理/投顾）→ 实名认证（身份证 + 人脸）→ 创作中心 → 创作权益 → 加入创作者计划，开通文章/视频/微头条收益 + 原创保护（0 粉可开），**不要开同步到抖音/西瓜**，不要勾首发。（10 分钟）
2. Yuan 手动：定 1 个财经兴趣认证方向 + 建 1 个专栏（如 `躺平的老黄·指标实验室`），关评论区外链，设“仅粉丝可评”试运行。（10 分钟）
3. Yuan 手动：首次扫码登录（给 v2 用）：本地 Chrome 打开 `https://mp.toutiao.com`，抖音 App 扫码，生成 `cookies/toutiao.json`（参考 `douyin.py` 模式，`.gitignore`，**本轮未碰**，以后不给密码，过期重扫）。（5 分钟）
4. 内容侧（自动）：每集 worker 额外产 `toutiao.md`（= `zhihu.md` 首段重写 200 字 + 删外链 + 加免责/AI 声明）+ `cover_toutiao_1024x678.jpg`（中心 70% 安全区，大字 ≥36px）+ `meta.json`（标题 15–30 字、话题、定时）。
5. 发布侧（人工 5 分钟/篇终审）：标题/封面/话题/原创勾选/广告勾选/AI 声明/免责/无二维码无外链无水印/>1 分钟视频通道/政治不发确认，然后发布。

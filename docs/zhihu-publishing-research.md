# Video Factory 发知乎可行性与限制调研

> 日期：2026-09-26。只调研和写文档：未上传任何视频，未改代码，未提交，未读取/导出/打印任何浏览器 cookie、token 或登录凭据。
> 频道笔名：`躺平的老黄`（全片只用笔名，不出现真名）。现有三类视频：①「什么指标不赚钱」回测系列（`type=indicator`，manifest 一图一段，约 240–300s，1920x1080，见 `docs/indicator-episodes.md`）；②书摘系列（`type=book`，3–4 分钟讲书，见 README）；③计划中的每日财经/政治/科技新闻（见 `docs/daily-news-video-design.md`）。
> 对照文档：`docs/bilibili-publishing-research.md`（B 站篇）。本篇为知乎专项：B 站篇里的 `open.bilibili.com` 投稿 API、分区 `tid`、创作中心网页上限等**不适用于知乎**，以本篇为准；财经/时政/AI 标注等监管红线两站通用，本篇只写知乎差异。
> 假设清单见文末 §8。本轮未使用用户浏览器已登录的知乎状态。
> 引用凡写【官方明确规定】指部委文件/知乎站内规范原文；凡写【社区经验】指第三方教程、专栏复盘、GitHub issue，未经官方确认。

**结论速览（5 句）：**

1. 知乎**没有个人可用的官方发布 API**——数据开放平台（`developer.zhihu.com`）只有搜索/热榜/直答/知识库等数据接口 + OAuth 第三方登录，没有视频/文章/回答写入接口，个人走不通。
2. 自动化现实路径只有**浏览器自动化（Playwright，推荐）**，复用本仓库已有的 Douyin/Xiaohongshu 模式；`biliup` 这类成熟投稿工具在知乎不存在，主流一键分发库（如 `dreammis/social-auto-upload`）支持 6 站但**不支持知乎**，需自研且必须保留人工审核闸。
3. 知乎是**图文问答站，不是视频站**：视频 2022 年后被弱化，流量远不如回答/文章；正确姿势是“一鱼三吃”——**回答（主）+ 文章/专栏（次）+ 视频（嵌入增强）**，不要只发独立视频。
4. 书摘最安全、指标回测次之（加免责即可），科技新闻可发，财经新闻只能发“无个股、无买卖点”的投资者教育，**政治/时政新闻建议不发**（个人无《互联网新闻信息服务许可》），全链路 AI（LLM 文案 + Edge-TTS 配音）**每篇必须主动声明 AI 生成**（2025-09-01 起强制）。
5. 同一成片可 YouTube/B 站/知乎复用，但知乎必须做图文重写（搜索标题 + 长尾话题 + 图表贴图 + 免责 + AI 声明），且**不能在正文/封面/评论挂 YouTube/B 站链接或微信号**（公开导流=折叠删文），优先级建议见 §6。

## 1. 发布途径：官方 API vs 浏览器自动化

### 1.1 官方数据开放平台（developer.zhihu.com）

**【官方明确规定】**

- 入口：`https://developer.zhihu.com/`，文档 `https://developer.zhihu.com/docs`，控制台 `https://developer.zhihu.com/console/api/v2/docs`，个人中心 `https://developer.zhihu.com/profile`。
- 现有接口（截至 2026-08 第三方整理，官网一致）：热榜 API、知乎搜索 API、全网搜索 API、直答 API、知识库列表/内容/上传/检索、用户创作内容读取（`我的创作 API`，回答/文章/视频/想法/问题**只读**）、关注/收藏、PDF 解析、PPT 生成。鉴权统一 `Authorization: Bearer <access_secret>` + `X-Request-Timestamp`（秒级 Unix 时间戳），`access_secret` 在个人中心生成；错误码 `0/10001/20001/30001/30002/...`。
  - 来源：官网文档页 + 第三方接入整理 `http://106.54.226.30:19120/zhihu-api`（仅作接口清单旁证）。
- OAuth：文档明确“知乎 OAuth 是为了集成知乎作为三方登录 + 获取授权用户个人信息”，申请需发邮件 `openplatform@zhihu.com`（主题 `<公司/组织/产品名称>申请接入知乎 OAuth 服务`，附应用名/简介/图标 ≥256x256）。**不是内容发布授权**，无 `ARC_BASE` 这类投稿 scope。
- 申请制：官网 FAQ “如何申请 API 访问权限？请发邮件，提供使用场景和预估调用量，1 个工作日内处理”；当前为邀测阶段，具体计费与商务团队谈。
  - 来源：`https://developer.zhihu.com/docs?key=hot_list_skill` 页面 FAQ。

**结论：官方发布 API 对本项目不可用。** 没有视频/文章/回答写入端点，`我的创作` 只是读自己已发内容。即使申请通过，也只能做选题（热榜/搜索找高热问题，见 §5.4），不能直传。B 站篇 §1.1 的企业执照/OAuth 投稿链路在知乎**不存在对应物**，不用再纠结。

### 1.2 非官方逆向 API（不推荐）

| 路径 | 状态 | 原理 | 评价 |
|---|---|---|---|
| `zhihu-api` / `zhihu-py` 等逆向 `https://www.zhihu.com/api/v4` | 零散、易断 | 逆向网页 XHR，Bearer/cookie + 签名，调回答/专栏/视频上传分片 | **不建议新用**：知乎《社区规范》明确禁“批量发布内容、发布机器生成的内容”，逆向高频=封号 + 无上游维护；且 2026 年开放平台已收编合规数据需求，逆向法律风险更高 |
| 第三方博客所谓“内容发布接口 ≤10 次/小时/账号” | 传闻 | 无官方出处 | **【社区经验】且不可信**，本表不做承诺；以创作中心实时行为为准 |

### 1.3 浏览器自动化（Playwright，唯一现实路径）

- 本仓库已有模式可直接复用：`apps/worker/src/publishers/douyin.py`、`xiaohongshu.py`（Playwright + cookie 登录态 + 文件夹任务 + 人工确认），`youtube.py`（Data API 直传，仅 YouTube 有官方 API）。
- 知乎侧现状**【社区经验】**：
  - 主流开源一键分发 `dreammis/social-auto-upload`（https://github.com/dreammis/social-auto-upload）支持抖音/小红书/视频号/TikTok/YouTube/Bilibili，**不支持知乎**——知乎页面结构变化快、风控严（盐值+威尔逊+举报众裁），维护者一般绕开。
  - 通用教程（如 `python+deepseek创作视频十——playwright自动上传视频` https://zhuanlan.zhihu.com/p/1934362734935401029 ，`利用 Playwright 自动上传文件` https://zhuanlan.zhihu.com/p/697538235）证明 Playwright `codegen + 文件上传` 技术上可行，但都是单站手写选择器，无知乎专用稳定库。
  - 微信视频号 Skill（`Stevewu422/auto-weixin-video-skill`）的安全实践可照搬：cookie 存本地 `cookies/*.json` 并 `.gitignore`，定期 `check_cookie`，发布频率控制，发布前人工确认。
- 风控分级（官方只笼统写“违规处理”，以下为**【社区经验】**为主）：
  - 低风险：单号、单 IP、每天 ≤1–2 更、自制原创、人工审后发布、模拟正常间隔（上传→填标题/简介/话题→预览→发布，间隔数分钟）。
  - 中风险：每天 5–10 更、定时机器人无间隔群发、同一内容多号重复投、评论区放站外链接/微信号。
  - 高风险：搬运/洗稿冒原创、影视/赛事/他人成片、无资质荐股+收费引流、多号同 IP 互赞互评刷榜（社区规范明确禁“批量互关互赞互评、抱团点赞、重复发布相同或相似内容”）。
  - 技术信号：上传 500/转码失败重试、发布后秒折叠/秒删（多为导流/时政/版权）、连续限流（推荐占比骤降、搜索不收录）。

**推荐方案与备选：**

- **推荐 A（v1）：半自动 + 人工一键**——worker 只生成 `output.mp4 + cover + meta.json（标题/简介/话题/专栏/回答正文.md）`，人工在知乎创作中心做最后一键发布（视频 + 文章/回答嵌入视频），保留 `PUBLISH_REQUIRE_REVIEW=1`。成本最低，合规最稳，也是知乎调性下唯一能做精图文的路径。
- **备选 B（v2）：worker 集成 Playwright 知乎发布器**——发布队列 + 重试 + 回读（内容 URL/状态），仍强制人工审核 + 单号限频 + cookie 保活。需自建选择器维护（知乎一改版就得跟），与 Douyin/Xiaohongshu 发布器同构。
- **不选**：官方开放平台直传（无接口）、逆向 `api/v4` 批量发（封号风险）、纯视频群发（知乎视频流量弱，见 §5.1）。

## 2. 账号要求

**【官方明确规定】**

- 注册与盐值：知乎盐值 0–1000，初始 260–300，每周更新；五维：基础信用/内容创作/友善互动/遵守规范/社区建设；盐值对应权益并**直接作用于推荐系统和赋权系统**。来源：https://www.zhihu.com/term/credit 。
- 基础信用：完善资料 + 绑手机号 + 个人认证 + 优秀答主等荣誉；昵称/头像/签名违规会被重置并扣分；禁言/锁定/封禁扣分。
- 提问/回答数量限制：官方规则中心明确“注册时间短的用户每日回答数量受限，随优质内容和赞同逐步放宽；日常使用一般不触发”。新号不要日更 5 篇，先养权重。来源：规则中心 `https://www.zhihu.com/column/c_1280179753018777600`。
- 创作者等级 Lv1–Lv10（创作分五维：活跃度/优质分/影响力/亲密度/成就分，日/周/月更）：Lv1 内容分析/盐选作者申请，Lv3 好物推荐基础/主页置顶/直播，**Lv4 内容自荐/视频收益/招募任务**，Lv5 赞赏，Lv6 品牌特邀，Lv7 自定义推广/圆桌主持，Lv9+ 品牌任务。**【社区经验整理自官方创作中心】**：https://baiyunju.net/11159 ，https://zhuanlan.zhihu.com/p/641432004 。以创作中心实时页为准。
- 视频收益：创作者等级 ≥Lv4 + ≥5 条原创视频（社区口径，官方以创作中心为准）；赞赏需 Lv5；付费咨询需盐值 >500；盐选专栏邀请制但 Lv1 可申请盐选作者。
- 认证：个人认证（职业/教育）+ 优秀答主；机构号独立盐值体系（本项目用个人号，笔名 `躺平的老黄`）。财经/法律/医学另有资质门槛（见 §4）。

**【社区经验】**

- 老号、高盐值、高创作者等级、无违规号审核更快、初始推荐更高；新号/有违规号会被更严审查。知乎从未公布“盐值加速公式”，按风控策略理解。
- 一机多号、同 IP 多号互赞会被判批量营销连坐；评论区违规不清理会连累内容限流；举报/众裁/公共编辑是涨社区建设分最快的方式，但不要恶意举报。
- 知乎问答有“威尔逊公式”加权排序（赞同/反对按答主领域权重加权，新回答有基础曝光，获赞速率决定爆发），运营本质是和算法博弈而非单纯堆量。来源：https://www.zhihu.com/question/307623383 下高赞解析（社区解读，非官方公式全文）。

**对我们的要求**：至少 1 个已绑手机 + 资料填满 + 个人认证的号，盐值目标 500+，创作者等级先冲 Lv4（解锁视频收益 + 内容自荐）；单号单 IP，不切号；新号前 2 周每天 ≤1 篇回答/文章 + ≤1 条视频，先回答案例见 §5.4。

## 3. 视频/图文规格

**【官方明确规定】少，【社区经验】多——下表已分区标注，以创作中心实时页为准。**

| 项 | 知乎口径 | 建议（沿用现有产出即可） |
|---|---|---|
| 容器/编码 | 官方无公开编码表；创作中心接受主流 MP4/MOV 上传 | **MP4 H.264 + AAC 48kHz**，与 YouTube/B 站统一，1080p 6–8Mbps，GOP ≤2s，8bit BT.709，最稳 |
| 分辨率/帧率 | 横竖均可；官方无强制 720p+ 文档 | **1920x1080 30fps** 横屏直接复用；竖屏如需再切 1080x1920（知乎竖视频消费存在但知识类横屏更适配图表） |
| 大小/时长 | 官方无公开“8GB/分 P”式文档 | 我们 4–8 分钟无压力；单文件建议 <2GB；超长拆回答多节而非分 P |
| 封面 | 官方强调不用低质/标题党图 | **1920x1080（与 B 站共用）<2MB JPG/PNG**，关键信息放中心 70% 安全区，大字 ≥36px；来源：B 站/知乎可共用封面尺寸 https://zhuanlan.zhihu.com/p/942317834 **【社区经验】**；book 的 3s 标题卡可直接当封面底，去黑边 |
| 视频标题 | 无 `tid` 分区概念，用**话题**代替 | 6–30 字中文，关键词前置，禁震惊体/承诺收益（“稳赚/翻倍/必涨”）；短时间不重复发同标题 |
| 简介/描述 | 可写长，支持时间轴/`@`/`#` | 首行纯文字 + 来源 + 免责 + AI 声明 + 素材授权（模板见 §5）；不要放外链/微信号（见 §4.7） |
| 话题/专栏 | 无 B 站 `tid`，靠话题 + 专栏分发 | 每篇 3–5 个细分话题（如 `MACD` 而非 `股票`），书摘加专栏；话题错=限流 |
| 文章/回答正文 | 文章建议 ≥1000 字含标题/摘要/关键词（社区投稿指南口径）；回答无字数上限但 300 字+配图才有创作分 | 指标文 1500–2500 字 + 5–8 张图表；书摘文 1500–3000 字；新闻回答 800–1500 字即可 |

分区注意：知乎**无分区投稿**，对应物是**话题 + 专栏 + 问题**。财经→话题 `股票/基金/量化交易/投资者教育`；书摘→专栏 + `读书/人文` 话题；科技→`数码/软件/人工智能` 话题；时政→**不碰**（见 §4.2）。

## 4. 内容规则（重点）

### 4.1 财经类：荐股、免责、持牌

**【官方明确规定 / 监管红线】**

- 非法证券投资咨询定义（证监会）：未经批准擅自提供证券分析/预测/建议并直接间接收费 = 非法。个人 UP 主无牌荐股即踩线（同 B 站篇 §4.1）。
- 知乎站内无单独《财经公约》全文页，但适用同一监管 + 社区规范；**类比口径**（B 站/抖音/视频号会跟进，知乎只会更严，因为问答长尾责任更重）：
  - 微信《视频号金融行业公约》（2026-04-01 生效，https://news.qq.com/rain/a/20260326A057S300）禁 8 类：违法推荐（明示暗示买卖时机/价格/预测走势）、承诺收益（保本/稳赚/翻倍）、恶意唱衰、违规服务、伪造背书、同质低质、虚拟币/NFT、站外引流；“基金经理”等号必须职业/机构认证且出镜人=认证人。
  - 抖音《财经行业公约（试行）》（https://www.bjjubao.org.cn/2026-04/14/content_48459.html）同理；雪球 2026-01 对 22 个违规财经大 V 永久封禁（见 B 站篇引用）。
- 知乎社区规范禁“虚假认证、恶意营销导流”，财经冒充持牌=虚假认证 + 误导（健康/财产安全类比健康领域细则：误导性内容降权，见规则中心）。

**必须做（财经每集/每篇）：**

- 不点名个股/基金代码、不给买卖价位、不预测“必涨/看到 XX 点”、不用暗号规避审核。
- 口播 + 正文双位置免责，模板：`本内容为投资者教育，不构成投资建议。历史数据仅供参考，过往业绩不代表未来表现。投资有风险，入市需谨慎。`
- 只讲已发生事实 + 宏观逻辑，不做单一操作结论；引用财报/央行来源并贴站内可查来源名（**不要贴站外链接**，见 §4.7）；收益对比图必须标“历史数据仅供参考”。
- 不卖课、不建收费圈、不留微信/QQ 引流（违规引流直接折叠封号）。

### 4.2 时政新闻类：资质要求（为什么建议不发）

**【官方明确规定】**

- 《互联网新闻信息服务管理规定》（https://www.gov.cn/gongbao/content/2017/content_5232377.htm）：向公众提供新闻信息服务（含报道 + 评论，政治/经济/军事/外交/突发）**须取得《互联网新闻信息服务许可证》**，只发境内法人，采编需新闻单位或主管单位，从业需记者证。个人**不可能取得**。
- 《网络短视频平台管理规范》+《网络短视频内容审核标准细则》（2019-01，中国网络视听节目服务协会）：平台实行**先审后播**，标题/简介/弹幕/评论全审；**不得转发 UGC 上传的时政类、社会类新闻短视频**，不得转发无首发资质 PGC 的时政节目；100 条细则覆盖政治/分裂/泄密/稳定等 21 类。来源：https://dun.163.com/news/p/duanshipin1 ，http://www.xinhuanet.com/zgjx/2019-01/10/c_137732598.htm 。
- 知乎时政主要是机构媒体号阵地，个人发时政=重点风控对象；问答的长尾搜索会放大时政责任（一年后还被搜到），比短视频更危险。

**结论：计划中的“每日政治新闻”建议不发。** 财经里的宏观政策解读可以做，**时政（选举/冲突/制裁/领导人活动）不做**。若非要试：只转述新华社/央视已发 + 注明来源名 + 多方说法 + 不预测不站队 + 接受被删；做好“发 10 删 9”的预期。

### 4.3 科技类

相对最安全。按话题定义走，禁整段搬运发布会原片；优先公司官方 press kit / IR 回放（署名 + 遵守其条款），CC-BY 按许可署名。AI 伪造“发布会现场”禁用。科技问答在知乎是仅次于财经的高需求区，可大胆做。

### 4.4 「自制」vs「转载/洗稿」

**【官方明确规定】**（知乎社区规范 + 规则中心）：

- 鼓励原创，禁抄袭剽窃；引用必须注明；禁洗稿整合、非授权转载；禁重复发布多篇相同或相似内容；禁批量发布、机器生成内容。来源：规则中心 `https://www.zhihu.com/column/c_1280179753018777600`，社区规范 `https://www.zhihu.com/term/community`（web 403 时以站内 App 可见原文为准，此处转述经多篇专栏交叉验证：https://zhuanlan.zhihu.com/p/1924567209340019345）。
- 对我们：三类内容都选**原创**（自研图表 + 原创解说 + Pexels/CC/官方素材二创），正文写清素材来源；绝不把 YouTube 成片不加改就当转载搬回来；同一主题多问题下不要复制粘贴同一回答（判恶意营销 + 限流）。

### 4.5 境外素材 / YouTube 同款限制

- 允许同成片多平台发，但版权系统独立：YouTube Content ID 过了 ≠ 知乎无事；知乎有查重 + 权利人投诉（影视/音乐最严），且问答的文字洗稿检测比视频更严（不要把高赞回答洗成脚本）。
- 安全栈（沿用 `docs/daily-news-video-design.md §5` + B 站篇 §4.5）：美国联邦 PD（17 USC §105 https://www.law.cornell.edu/uscode/text/17/105）、央行/公司官方回放与 press kit、Pexels（https://www.pexels.com/license/）/Pixabay（https://pixabay.com/service/license-summary/）、Wikimedia CC-BY/SA/PD（https://commons.wikimedia.org/wiki/Commons:Licensing）、YouTube CC-BY（署名 + 警惕片内插曲）。
- 禁用：影视/综艺/体育/演唱会/MV/纪录片正片、他人成片（无 CC）、GNews/NewsAPI 配图原样铺满（第三方版权归原主）、去水印/破解 DRM。
- 每段素材落 `material_attribution.json` + 正文【素材与授权】段，缺一不可。

### 4.6 AI 生成配音/内容是否需要标注

**【官方明确规定】是，必须标注。**

- 《人工智能生成合成内容标识办法》（四部门，2025-03-07 发，2025-09-01 施行，https://www.gov.cn/zhengce/zhengceku/202503/content_7014286.htm ；新华解读 https://www.news.cn/politics/20250314/b7a24028f2924b7681e6ed1bfbd8fade/c.html ；澎湃全文 https://m.thepaper.cn/newsDetail_forward_31547777）+ 国标 GB45438：文本/音频/图片/视频/虚拟场景要加**显式标识**（可感知）+**隐式标识**（文件元数据）。用户发布 AI 内容须**主动声明**并用平台标识功能；不得删改伪造标识。
- 知乎规则中心已有 AI 细则（`https://www.zhihu.com/column/c_1280179753018777600` 内《AI 创作相关规范》）：站内内容无论是否 AI 辅助均受社区规范约束，AI 相关需按细则声明；六大平台 2025-09-01 同步上线“AI 生成”角标 + 元数据标识，创作者必须主动标注（PwC 解码 https://www.pwccn.com/zh/tmt/method-identifying-synthetic-content-generated-ai-sep2025.pdf）。
- 我们全链路 AI（LLM 脚本 + Edge-TTS 配音）**每集/每篇必声明**：视频勾选平台“AI 生成”标识 + 正文首尾加一句 `本文/本视频文案/配音由 AI 辅助生成，已按平台规范声明。` + 视频起始画面显著提示（办法第四条）。

### 4.7 营销导流限制（能否挂 YouTube/B 站链接）

**【官方明确规定】不能公开挂。**

- 知乎社区规范禁“一切可能损害用户和平台利益的导流、营销推广行为”，包括头像/封面/昵称/标题等显著位置加导流信息，夹带二维码/网址/邮箱/同音谐音字均违规。来源：`https://www.zhihu.com/question/19790711`（规范问答页）+ 机构号规范 `https://www.zhihu.com/org_use_norm` + 导流规则解析 https://omnigoai.com/zh/blog/zhihu-daoliu-rules **【社区经验，但与官方原文一致】**。
- **【社区经验】**2026 合规路径只有五条：知+投放卡片、落地页表单、主页+置顶回答、私信被动咨询、Live/盐选附赠（https://zhuanlan.zhihu.com/p/2027942933672764216）。直接在回答里放微信号/二维码=折叠删除；私信群发广告=举报禁言。知乎相对最宽松的是“主页简介 + 置顶回答 + 私信自动回复”，但公开外链仍不行。

**对我们：YouTube/B 站链接一律不挂正文/封面/评论。** 最多在主页简介写“全网同名 `躺平的老黄`，视频版在 B 站/YouTube”，正文用文字来源名代替链接（如“数据见美联储官网 FOMC 回放”而不贴 URL）。想导流只能靠被动咨询（用户私信问“视频在哪看”再回），且不能批量。

### 4.8 审核时长、常见退回、限流

- 审核：先审后播，机器（拆帧 OCR/语音转文本/查重）+ 人工。时长 **【社区经验】**图文回答一般数分钟到数小时，视频 1–2h 到半天，10–22 点快，深夜慢；敏感/版权可数天；秒删多为导流/时政/侵权。
- 常见退回/折叠：话题错、标题党、版权音乐/影视、无资质财经冒专家、时政无资质、低质（<720p、音画不同步、黑边、证件号/微信号未打码）、重复发布、洗稿抄袭、外链导流。
- 限流（【社区经验】）：威尔逊得分低（赞同少/反对多/领域权重低）、盐值低、粉丝占比过高未破圈、评论区失管连坐、设备 IP 污染、无效播放。整改后 3–7 天恢复；红线（涉政/色情/恶意对立）申诉极难。

## 5. 现有三类视频逐一判断 + 知乎内容形态打法

### 5.0 先讲形态：视频、文章、回答、想法的流量差异（知乎专项核心）

| 形态 | 流量逻辑 | 适合我们 | 做法 |
|---|---|---|---|
| **回答** | 搜索 + 威尔逊排序，长尾最强，常看常新，百度/微信搜一搜/站内搜三吃 | **主战场**：指标系列 + 科技解读 | 每集绑定 1–3 个存量高关注问题，先答存量大问题，不自问自答；正文嵌入当集视频 + 图表 |
| **文章/专栏** | 关注分发 + 搜索长尾， систематический，可赞赏/付费/盐选，可投双专栏 double 曝光 | **次战场**：书摘系列（专栏连载）+ 指标合集 | 建专栏 `躺平的老黄·指标实验室` / `躺平的老黄·讲书`，每集一篇，文末挂系列目录 |
| **视频（独立）** | 信息流 + 关注，2020 年曾推独立入口，2022 年视频部门裁员 60%、一级入口改回“想法”，战略被弱化 | **增强件，不单独首发** | 每集视频上传后，**嵌入对应回答/文章**，不指望独立视频爆款。数据旁证：https://www.jiemian.com/article/7355418.html **【社区经验/媒体报道】** |
| **想法** | 短内容信息流，轻量，适合预告/金句/单图 | 辅助：每日新闻快讯、图表一句话 | 新闻选题先发想法试水，数据好再扩成回答；不要把长视频首发在想法 |

一句话：**在知乎，不做“视频 UP 主”，做“答主 + 专栏作者”，视频只是回答的附件。**

### 5.1 「什么指标不赚钱」回测系列 → ✅ 适合发，知乎打法 = 回答 + 文章 + 视频三件套

- 话题：`股票、技术分析、量化交易、MACD、KDJ、布林线、投资者教育`（3–5 个细分话题，不要只打 `股票`）。类型：**原创**。
- 为什么适合：自研图表 + 原创解说 + 数字原样校验，独创性强；讲“为什么不赚钱”是风险教育，天然合规；且知乎有十年沉淀的指标类高热问题（见 §5.4），长尾搜索精准。
- 必须改（4 处）：
  1. 口播/正文加免责（见 §4.1 模板），标题禁“稳赚/必胜/翻倍”，保留“控制仓位/只做趋势”。
  2. 封面：用 `cover_presenter.png`（已有笔名），去黑边/边框，确保 16:9。
  3. 勾选 AI 声明；正文贴图表数据来源 + `key_point` 数字出处；保留 `script_review.md` 备申诉。
  4. **图文重写**：不能只贴视频 + 一句话，必须按 §5.4 模板写 1500–2500 字文章/回答（图表逐张贴 + 解读），视频嵌在开头或对应小节。
- 风险：低。唯一折叠点可能是“信息不准确”，靠数字校验 + 来源可追溯解决。

### 5.2 书摘系列 → ✅✅ 最适合发，知乎起量靠它

- 话题/专栏：建专栏连载 + `读书、心理学、经济学、人文` 话题。类型：**原创解读（二创）**。
- 为什么最适合：无荐股、无时政、无版权原片，平台鼓励知识区二创；且图文是知乎基本盘，书摘文章天然适配搜索（书名长尾词）。
- 必须改（3 处）：
  1. 正文写 `书名 + 作者 + 出版社 + 本视频为原创解读，非原书朗读`，避免整章朗读（合理引用：观点转述 + ≤2 数字/段）。
  2. 开头保留 `大家好，我是躺平的老黄。` + 封面署名，人设统一。
  3. 勾选 AI 声明（文案/配音 AI 辅助）。
- 风险：极低。注意别用影视原声做 BGM，别在封面放二维码/联系方式。可申请盐选作者/付费专栏做变现（Lv1 可申请）。

### 5.3 每日财经/政治/科技新闻 → ⚠️ 拆开看：财经限条件可发，科技可发，政治不发

- **财经新闻（宏观/央行/财报，无个股）→ ⚠️ 限条件可发**：只讲已发生事实 + 官方来源名；删个股代码/买卖点/涨跌预测；加免责 + `事实截至 XX 时间`；无强相关官方视频就转数据卡，不要硬凑空镜。形态上**回答 > 想法 > 文章**（新闻时效短，不值得开专栏）。
- **科技新闻 → ✅ 可发**：用官方 keynote/IR + press kit 图，署名；禁新闻台片段原样引用。知乎科技问答需求大，可做。
- **政治/时政新闻 → ❌ 建议不发**：个人无新闻许可，知乎退回/折叠重灾区，且问答长尾会放大责任。若非要试：只转述新华社/央视已发 + 注明来源 + 多方说法 + 不预测不站队 + 接受被删；做好“发 10 删 9”的预期。

### 5.4 「什么指标不赚钱」如何从每集已有产出自动生成高质量知乎文章/回答

每集已有：`脚本（script.json/script.md）`、`回测图表 PNG（manifest.json 顺序）`、`manifest.json（title/key_point）`、`summary（摘要）`。映射关系：

## 6. 和 YouTube/B 站同步发布的建议 + 三平台优先级

- **同一成片能复用**：容器/编码统一 `MP4 H.264 + AAC 48kHz`，1080p 6–8Mbps，三站通吃。英文版（`en-US-AriaNeural`）只发 YouTube。
- 必须做的平台差异化：

| 项 | YouTube | B 站 | 知乎（差异最大） |
|---|---|---|---|
| 标题 | 英文 hook + 关键词 + 系列名，可长 | 6–30 字中文，关键词前置，禁震惊体；短时间不重复 | **回答用问题原标题（不动）；文章用搜索友好标题（含书名/指标名+疑问词），不承诺收益** |
| 封面 | 1280x720 | 1920x1080（或 1146x717），禁边框/黑屏 | **与 B 站共用 1920x1080**，但知乎回答首图会被裁剪，关键信息放中心 |
| 简介/正文 | 长描述 + 章节 + 外链 + playlist | 首行纯文字 + 来源 + 免责 + AI 声明 + 素材授权 | **必须重写 1500 字+图文**，视频只是附件；禁外链，来源用文字名 |
| 标签/话题/分区 | tags + playlist（财经/科技/读书三列表） | `tid`（207/228/188 系/资讯）+ ≤10 标签 | **话题 3–5 个细分 + 专栏**，无 `tid`；错话题=限流 |
| 字幕 | 可传 SRT + 多音轨 | 烧录 ASS 大字（landscape ≤26 字） | 视频内烧录字幕不变；正文另配文字版（搜索引擎不读视频字幕） |
| 时长 | 可 10 分钟+ | 6–8 分钟完播最稳 | **视频 4–8 分钟 + 正文长尾**，完播不行靠搜索补 |
| 发布时间 | `unlisted` + `publishAt` 定时 | 预留 2–6h 审核，10–22 点投 | **回答/文章无“定时公开 API”，人工在白天发**；留出审核 + 首轮推荐观察期 |
| 版权/音乐 | Content ID | 查重 + 投诉制 | **查重 + 洗稿检测 + 举报众裁**，文字洗稿比视频搬运判得更严 |
| 导流 | 可挂外链/片尾屏 | 评论区禁站外引流 | **禁一切公开外链/微信号**，只能被动私信（见 §4.7） |

- 切忌：同一文案同一分钟机器人群发、关联小号重复投、只改标题复投（三站都会判垃圾内容，知乎还会扣盐值）。

**三平台优先级（与 B 站篇对照结论）：**

| 系列 | 第一优先 | 第二优先 | 第三优先 | 理由 |
|---|---|---|---|---|
| 指标回测 | YouTube（英文增量 + 变现） | B 站知识-财经 `207`（视频基本盘） | 知乎回答+文章（搜索长尾，需图文重写，工作量最大但护城河最深） | 知乎单发视频没流量，必须配图文；但一旦排上搜索，长尾可吃 1–2 年 |
| 书摘 | 知乎专栏+回答（基本盘，搜索+付费） | B 站知识-人文 `228` | YouTube（英文版增量） | 书摘在知乎是主场，B 站是客场，YouTube 靠翻译 |
| 每日财经新闻 | YouTube（时效 + playlist） | B 站资讯/知识 `207`（限条件） | 知乎想法/回答（只做宏观+科技，时效过后即沉，不做专栏） | 新闻在知乎只有短保质期，不值得重投入 |
| 科技新闻 | 三站可并列 | — | — | 科技最安全，同一成片三发，只改标题话题 |
| 政治/时政新闻 | **三站都不发** | — | — | 个人无许可，三站都是重灾区 |

 phasing：P0 先跑通 YouTube + B 站视频链（已有 runbook），P1 再开知乎图文链（每集多 1–2h 重写成本），P2 再考虑 Playwright 自动发布（知乎选择器维护成本高，手动很久都不亏）。

## 7. 需要用户亲自做的事情清单

1. 账号：完成**手机绑定 + 资料填满 + 个人认证**，目标盐值 500+、创作者等级 Lv4（解锁视频收益 + 内容自荐）；定笔名 `躺平的老黄` + 头像 + 简介（别写“基金经理/投顾”，写了就得职业认证）。
2. 定位：建 2 个专栏（`指标实验室` / `讲书`），定首发话题（回测：量化/指标话题；书摘：读书话题）；**政治是否放弃**（建议放弃，见 §4.2）。
3. 资质：无金融牌照=接受“只做投资者教育、不荐股”；若要发强专业内容，去考证券/基金从业并完成知乎职业认证（否则限流/折叠）。
4. 授权：知乎登录态只能用户亲自扫码登录生成 cookie（参考 `douyin.py/xiaohongshu.py` 模式），**本轮未碰**；以后也不要给密码，定期重扫，取消授权随时在知乎设置里操作。
5. 开放平台（可选，选题用）：在 `developer.zhihu.com/profile` 生成 `access_secret`（只读热榜/搜索，**不要放进公开文档或代码仓库**，本轮未生成），用于 P1 自动找高热问题；邮件申请 `openplatform@zhihu.com` 只有需要 OAuth 登录集成时才用，纯发布不用。
6. 每集终审（10 分钟，比 B 站多 5 分钟图文检查）：标题/封面/话题/专栏/免责/AI 声明/素材授权/视频嵌入位置/无外链无微信号，政治类多加一道“不发”确认。
7. 运维：评论区每天看一次（违规评论不清理会连坐），被折叠 15 天内申诉（留 `script_review.md` + 图表工程文件）；多做举报/公共编辑涨社区建设分，但不恶意举报。

## 8. 假设清单（无人值守已按此执行）

1. 未上传视频、未改代码、未提交、未读任何 cookie/token/凭据、未用浏览器登录态。
2. 个人创作者、无企业执照、无金融/新闻牌照，按最严口径给建议。
3. 默认中文、横屏 1080p30、H.264 + AAC，封面 16:9，笔名 `躺平的老黄`。
4. 官方口径以开放平台/社区规范/规则中心/部委文件为准，其余标【社区经验】；知乎话题/限额/收益门槛以创作中心实时页为准，不硬编码。
5. 若官方/CC 无强相关视频，宁可转数据卡也不硬凑空镜/新闻台片段（沿用新闻设计文档 §5 分级）。
6. 知乎视频流量弱化、图文为主是基于 2022–2026 媒体报道 + 社区复盘的判断（见引用），若知乎后续重推视频，本篇 §5.0 需重估，但“回答+文章承载视频”的姿势不变。

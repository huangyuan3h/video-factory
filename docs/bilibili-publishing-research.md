# Video Factory 发 B 站（bilibili）可行性与限制调研

> 日期：2026-09-26。只调研和写文档：未上传任何视频，未改代码，未提交，未读取/导出/打印任何浏览器 cookie、token 或登录凭据。
> 频道笔名：`躺平的老黄`（全片只用笔名，不出现真名）。现有三类视频：①「什么指标不赚钱」回测系列（`type=indicator`，manifest 一图一段，约 240–300s，1920x1080，见 `docs/indicator-episodes.md`）；②书摘系列（`type=book`，3–4 分钟讲书，见 README）；③计划中的每日财经/政治/科技新闻（见 `docs/daily-news-video-design.md`）。
> 假设清单见文末 §8。本轮未使用用户浏览器已登录的 B 站状态。

**结论速览（5 句）：**

1. B 站官方开放平台（`open.bilibili.com`）投稿 API **不对个人开放**——需企业营业执照 + 公章承诺函 + 2–3 工作日审核 + 运营报备，个人 UP 主走不通。
2. 自动化投稿的现实路径是 **biliup（推荐）**这类逆向 Web/客户端接口的开源工具 + 人工审核闸；`bilibili-api-python` 已于 2026-07 因侵权函停更，不建议新用。
3. 书摘最安全、指标回测次之（加免责声明即可发），科技新闻可发，财经新闻只能发“无个股、无买卖点”的宏观/财报解读，**政治/时政新闻建议不发**（个人无《互联网新闻信息服务许可》）。
4. 我们现有 1920x1080 H.264 MP4 + 云健配音 + 烧录字幕的技术栈可直接复用，但投稿时必须勾选 **AI 生成声明**（2025-09-01 起强制），简介加风险提示，封面按 16:9 重做。
5. 同一成片可 YouTube/B 站复用，但标题、封面、简介、标签、分区必须按平台差异化，不能机器人式群发。

## 1. 发布途径：官方 API vs 开源工具

### 1.1 官方开放平台（open.bilibili.com）

**【官方明确规定】**

- 入口：`https://open.bilibili.com/`，文档中心 `https://openhome.bilibili.com/doc`，管理规范 `https://open.bilibili.com/agreement/management-protocol`。
- 入驻条件：提交最新《企业法人营业执照》副本（有效期 1 个月以上）+《入驻承诺函》加盖公章，信息必须一致，彩色扫描件。第三方教程明确写“**暂未开通个人开发者的申请入驻**”：
  - https://www.explinks.com/api/scd20240709052919a4a3d7
  - http://m.diansan.com/n/130079.htm
- 审核周期：**【社区经验】**2–3 个工作日（第三方入驻攻略口径；官方只写“审核通过后即可创建应用”）。
- OAuth 流程（标准授权码模式）**【官方明确规定】**：
  1. 入驻 + 建应用得 `client_id / client_secret`，申请权限点（如投稿 `ARC_BASE`）。
  2. 引导用户到 `https://account.bilibili.com/pc/account-pc/auth/oauth?client_id=...&gourl=...&state=...` 同意授权。
  3. 回调带 `code`（`{return_url}?code=...&state=...`），服务端用 `code + client_id + client_secret` 调 `POST https://api.bilibili.com/x/account-oauth2/v1/token`（`grant_type=authorization_code`）换 `access_token + refresh_token + expires_in + scopes`。
  4. 过期前用 `POST .../refresh_token`（`grant_type=refresh_token`，`refresh_token` 一次性）续期；过期则需用户重新授权。用户可在授权管理里随时取消。
  - 文档：https://bilibili.apifox.cn/doc-7492454 ，https://bilibili.apifox.cn/doc-885676
- 投稿接口（需 `ARC_BASE` + 用户授权 + HMAC-SHA256 2.0 签名头）**【官方明确规定】**：
  - `POST https://member.bilibili.com/arcopen/fn/archive/add-by-utoken`，前置需完成视频/封面上传预处理拿 `upload_token`。
  - 字段：`title`（<80，短时间不可重复）、`tid`（分区 id，调分区接口取）、`copyright`（1 原创/2 转载，转截需 `source`）、`tag`（英文逗号分隔，总长 <200）、`desc`（<250）、`cover`（须由上传封面接口得到）、`no_reprint`（0 允许转载/1 不允许）、`topic_id/mission_id`（默认不填）。
  - 文档：https://openhome.bilibili.com/doc/4/f7fc57dd-55a1-5cb1-cba4-61fb2994bf0f
  - 稿件提交后有审核过程，期间不对外开放；**非正式会员单日最多投递 5 个稿件**（开放平台文档原话，可答题转正解除）。
- 另一条官方路径“唤起粉端投稿”`POST /arcopen/fn/resource/add_share`（`scene_code=ARC_APP_SHARE`）：需先入驻 + 标准授权 + 发邮件向运营报备 `biz_code`，返回 `link_url` 让用户在装有 B 站客户端的设备上打开并**手动确认投稿**。不算全自动直传。文档：https://bilibili.apifox.cn/doc-7497592 ，https://bilibili.apifox.cn/doc-7498938

**结论：官方 API 对本项目不可用。** 我们是个人、无企业执照，走不到 `client_id` 这一步。即使未来注册公司，还需运营报备 `biz_code`，重人力，不适合 v1。

### 1.2 开源工具（逆向接口）：原理、稳定性、封号风险

| 工具 | 状态 | 原理 | 评价 |
|---|---|---|---|
| **biliup（推荐）** https://github.com/biliup/biliup ，文档 https://biliup.github.io/biliup/docs/guide/introduction/ ，分区表 https://biliup.github.io/tid-ref.html | 活跃（Rust 后端 + Python 包 + WebUI，`biliup upload/login/renew/server`） | 逆向 Web/客户端投稿链路：`member.bilibili.com/preupload` 取线路 → 分片直传 upos（国内 `bda2`，国外 `ws/qn`，或 `bupfetch` 第三方中转）→ `cover_up` 传封面 → `/x/vu/web/add?csrf=bili_jct` 提交。登录态靠 `SESSDATA + bili_jct (+DedeUserID)` cookie 文件（支持扫码/短信/浏览器/网页 cookie 登录，存 `cookies.json`）。支持多 P、线路选择、并发数、延后发布（2h–15 天） | 社区主流自动化方案，断点续传、线路探测较成熟。**【社区经验】**单号每天 1–2 更稳定；高频搬运、多号同 IP、录播 24x7 高频会触发 `-663 鉴权失败，请联系账号组`、500 重试、限流（见 https://github.com/biliup/biliup/issues/1442）。属非官方，B 站可随时改签名/风控 |
| `bili_webup / biliup-rs` 库 | 活跃（biliup 内核拆出的投稿库） | 同上投稿链，供外部项目 `import` 调用 | 适合我们 worker 集成，比 CLI 更易做审核闸；同样非官方 |
| `bilibili-api-python`（Nemo2011） | **已停更，不推荐新用** | 逆向非公开接口 SDK（含投稿分片上传） | 2026-07-06 接到侵权告知函（突破登录态/反爬签名、抓 OGV/弹幕反查身份等），作者声明停止维护并永久关停：https://github.com/nemo2011/bilibili-api/blob/main/README.md 。继续用=无上游安全更新 + 法律风险更高 |
| 手工/半自动：创作中心网页 + 投稿模板 | 官方 | `member.bilibili.com` 创作中心上传 + 投稿模板 API（`tid/title/tags/description/copyright`，见社区 SDK https://github.com/difyz9/bilibili-go-sdk/blob/v0.0.8/bilibili/creativecenter_upload.go） | 最稳、零封号风险，适合 P0。缺点是无人值守程度低 |

**封号/限流风险分级（【社区经验】为主，官方只笼统写“违规处理”）：**

- 低风险：单号、单 IP、每天 ≤2 更、自制原创、人工审后发布、模拟正常上传间隔。
- 中风险：每天 5–10 更、定时机器人无间隔群发、多 P 拆分绕审、标题党。
- 高风险：搬运/无授权转载冒自制、影视剧/赛事/他人成片、同一内容多小号重复投（官方判“垃圾内容”永封：大批量投稿、关联小号反复投类似内容、机器人无视质量快速发布，见 §3 引用）、 Comment 区放站外引流/收费荐股。
- 技术信号：`-663`、上传 500、投稿被锁（<10 分钟速锁多为侵权/不适宜）、连续 3 个视频播放 <均值 50%（权重降）。

**推荐方案与备选：**

- **推荐 A（v1）：半自动 + biliup CLI**——worker 只生成 `output.mp4 + cover + meta.json（标题/简介/标签/tid/copyright）`，人工在创作中心或 `biliup upload` 做最后一键发布，保留 `PUBLISH_REQUIRE_REVIEW=1`。成本最低，合规最稳。
- **备选 B（v2）：worker 集成 `bili_webup` 库**——发布队列 + 重试 + 回读（稿件状态/播放 URL），仍强制人工审核 + 单号限频 + `renew` 保活。需自建 cookie 轮换与风控（不同于 YouTube OAuth，此处是 cookie，易过期）。
- **不选**：官方开放平台（个人无资格）、`bilibili-api-python`（停更）、纯录屏/搬运流。

## 2. 账号要求

**【官方明确规定】**

- 注册 → 答题转正：新号默认“注册会员”，需社区规范答题 ≥60 分（100 题/60 分钟）成为“正式会员”才有投稿、弹幕、评论全功能；也可用 Lv5+ 用户的邀请码转正。来源：B 站 UP 主成长指南（https://activity.hdslb.com/blackboard/static/20220507/c74857cd3d199e15a1fbada58d8a9a44/zGKJ6iEQ0X.pdf）。
- 投稿需 **Lv1 + 绑定手机号 + 实名认证**（自 2017-07-05 起，UP 主上传/新增/编辑/换源均需实名；一张身份证只绑一个号，提现银行卡须同人；海外用护照/通行证/居住证）。未实名只能看不能投。
- 等级 Lv0–Lv6 靠经验（登录/观看/投币/分享/投稿），Lv1 解锁投稿，Lv2 评论，Lv3 高级弹幕，Lv5/6 邀请码等。等级与投稿上限无官方挂钩公式。
- 每日投稿上限：开放平台文档只明确“**非正式会员单日最多 5 稿**”；网页端文件上限已从 4GB 升至 **8GB/分 P**（创作力 50 + 信用 80 可 16GB，见社区 SDK 注释与教程）。**【社区经验】**普通用户约每天 2 个/共 20GB/单文件 2GB、高级会员约每天 10 个/单文件 4GB 的说法多见于 2024 年问答，非官方口径，**以创作中心实时页面为准**，本表不做承诺。
- 认证：黄 V（站内 10w 粉 / 站外 50w / 海外 10w / 社会名人）、蓝 V（企业/机构/媒体）。财经/法律/医学另需**资质认证**（见 §4）。

**【社区经验】**

- 老号、高等级、高信用、无违规号审核更快、推荐权重更高；新号/有违规号会被更严审查。但 B 站从未公布“等级加速审核”公式，按“玄学 + 风控策略”理解即可。
- 一机多号、同 Wi-Fi 多号互投/点赞会被判“网络环境异常”连坐限流；评论区违规不清理会连累视频限流。

**对我们的要求**：至少 1 个已转正 + 实名 + 绑手机的号，养到 Lv2+ 再批量发；单号单 IP，不切号；大会员仅改善观看画质，不放宽上传时长限制。

## 3. 视频规格

**【官方明确规定】**（开放平台投稿接口 + 创作公约；第三方教程为社区经验）

| 项 | 官方口径 | 社区经验/建议 |
|---|---|---|
| 容器/编码 | MP4、FLV、AVI、MOV、WMV；推荐 **H.264 MP4 + AAC** | H.265 可投但会被二压；MKV、10bit、BT.2020/HDR 慎用；GOP ≤2s、8bit、BT.709、方形像素最稳 |
| 分辨率/帧率 | 720p 及以上，支持 4K | **1920x1080 30fps** 与我们现有产出一致即可；60fps 适合动作/教程；竖屏用 1080x1920 另做封面 |
| 码率 | 开放平台不限；官方教程建议 1080p 约 8Mbps，4K 更高 | 1080p 按 **6–8Mbps** 导出（VBR 一次编码，High@5.1），二压损失最小；不要超 20Mbps 硬顶 |
| 音频 | AAC/MP3 | **AAC 48kHz 320kbps 立体声**；Edge-TTS 输出先转码到此规格再合成 |
| 大小/时长 | 网页端 **8GB/分 P**；单 P 时长普通号约 60 分钟内，认证号可申请 240 分钟（社区口径，官方无统一时长页） | 我们 4–8 分钟完全无压力；分 P 总时长不限，超长拆 P |
| 封面 | 16:9，JPG/PNG；官方客服强调**不用边框、不用黑屏/模糊图、不冒充官方角标** | 建议 **1920x1080（备选 1146x717）<2MB**，关键信息放中心 70% 安全区，大字 ≥36px；我们 book 的 3s 标题卡可直接当封面底，但要去掉黑边 |
| 标题 | 接口 `<80`（短时间不可重复）；App 端约 60 字 | 网页建议 **6–30 字**，关键词前置，禁“震惊/逆天/限时免费/全网首发”、禁夸张挑衅煽动断章取义；标题党会被减推荐/退回 |
| 简介 | 接口 `desc <250`；网页端可写到约 2000–5000 字（含时间轴、`@`、`#`） | **注意 API 与网页限制不一致**：走 biliup/逆向接口按网页长简介可过，走官方开放平台只能 250 字。建议首行纯文字，必含：来源 + 免责 + AI 声明 + 素材授权（见 §4–§5 模板） |
| 标签 | 接口总长 `<200` 英文逗号分隔；网页端最多约 10 个（常用 5 个） | 每标签 ≤12 字，只写内容相关词（人物/概念/属性），不要蹭无关热词 |
| 分区 `tid` | 调接口动态取（B 站会改版，不要硬编码死） | 财经→**知识-财经商业 `tid=207`**（主分区 `36`）；书摘→**知识-人文历史 `228`**；科技→**科技 `188`** 下数码 `95`/软件 `230`/计算机 `231`；纯时效新闻→**资讯**（新版 `/c/information/`：时政 `2080`/海外 `2081`/社会 `2082`/综合 `2083`；旧 `tid` 体系 `51` 只是番剧资讯，不要用）。投稿模板参考 https://biliup.github.io/tid-ref.html 与 https://lxb007981.github.io/bilibili-API-collect/video/video_zone.html |

分区注意：知识区/科技区官方分区指南要求**转载注明来源**；财经/法律/医学健康有额外资质门槛（见 §4）。

## 4. 内容规则（重点）

### 4.1 财经类：荐股、免责、持牌

**【官方明确规定 / 监管红线】**

- 非法证券投资咨询定义（证监会）：未经批准擅自提供证券分析/预测/建议并直接间接收费 = 非法。个人 UP 主无牌荐股即踩线。
- B 站知识-财经商业分区指南（https://www.te5.cn/hotnews/20220221216913.html 转述官方分区规范）：**须通过金融资质认证；未通过者不得随意发布投资指南等强专业性内容**，禁违规商业推广。B 站内部曾把投资类列为风险类别，对荐股视频限流/要求 CFA（见 https://www.manloong.com/baiyin/20210218/1814215.html）。
- 全网趋严（供类比，B 站会跟进）：微信《视频号金融行业公约》（2026-04-01 生效，https://news.qq.com/rain/a/20260326A057S300）禁 8 类：违法推荐（明示暗示买卖时机/价格/预测走势）、承诺收益（保本/稳赚/翻倍）、恶意唱衰、违规服务、伪造背书、同质低质、虚拟币/NFT、站外引流；要求“基金经理”等号必须职业/机构认证且出镜人=认证人。抖音 2025-11《财经行业公约（试行）》同理（https://www.bjjubao.org.cn/2026-04/14/content_48459.html）。
- 罚单不是故事：广东证监局吴某平无证荐股没收 255.17w + 罚 200w；雪球大 V 金永荣“抢帽子”被罚 + 3 年市场禁入；深圳证监局严禁直播荐股（http://stock.caijing.com.cn/20241111/5050396.shtml）。

**必须做（财经每集）：**

- 不点名个股/基金代码、不给买卖价位、不预测“必涨/看到 XX 点”、不用暗号（白水/券券）规避审核。
- 口播 + 简介双位置免责，模板：`本视频为投资者教育，不构成投资建议。历史数据仅供参考，过往业绩不代表未来表现。投资有风险，入市需谨慎。`
- 只讲已发生事实 + 宏观逻辑，不做单一操作结论；引用财报/央行来源并贴链接；收益对比图必须标“历史数据仅供参考”。
- 不卖课、不建收费圈、不留微信/QQ 引流（违规引流直接封）。

### 4.2 时政新闻类：资质要求（为什么建议不发）

**【官方明确规定】**

- 《互联网新闻信息服务管理规定》（https://www.gov.cn/gongbao/content/2017/content_5232377.htm）：通过网站/App/公众账号等向公众提供新闻信息服务（**含报道 + 评论**，政治/经济/军事/外交/突发），**须取得《互联网新闻信息服务许可证》**。许可只发给**境内法人**，采编发布还要求是**新闻单位或新闻宣传部门主管单位**，从业人员须持记者证。个人 UP 主**不可能取得**。
- 无资质账号不得发布/转载时政新闻；转载只能转中央/省级直属新闻单位等稿源名单内单位，且注明来源/原作者/原标题/编辑，不得歪曲篡改（国信办稿源名单制，2025 年起“持证亮牌”红 V：https://zh.wikipedia.org/zh-cn/互联网新闻信息服务许可证）。
- B 站资讯区（时政 `2080` 等）主要是媒体/机构号阵地，个人发时政=平台重点风控对象。

**结论：计划中的“每日政治新闻”建议不发。** 即使做到双源交叉、中立词、官方画面，仍是无资质采编+时政评论，退回/限流/封号概率远高于财经/科技。财经里的宏观政策解读可以做，**时政（选举/冲突/制裁/领导人活动）不做**。

### 4.3 科技类

相对最安全。按科技区分区定义走（数码/软件/计算机/科工机械/极客 DIY），禁整段搬运发布会原片；优先公司官方 press kit / IR 回放（署名 + 遵守其条款），CC-BY 视频按许可署名。AI 伪造“发布会现场”禁用。

### 4.4 「自制」vs「转载」

**【官方明确规定】**（https://member.bilibili.com/studio/convention/content?index=3-1 ，https://www.bilibili.com/opus/844447315521437703）

- 自制 = UP 主或团队构思创作、有独创表达；或本人二创加工；或获版权方授权。转载 = 搬运他人作品。
- **不属于自制**：完整搬运/简单增删拼接头/调换顺序；无加工纯截取；未经授权自加字幕；录屏未参与制作的作品；代投/授权搬运；倍速/倒放/镜像/调色/补帧；补档他人删除内容。
- 转载冒充自制 = 严重违规：管理员改/下线，创作激励三振（提醒 → 封禁无收益 → 清退，见 https://www.ostmcn.com/article-407.html）。
- 撞车：同内容只留一个，画质高 + 时间早优先；发转载前先站内搜。
- 退回申诉：稿件管理 → 申诉，**15 天有效**，留工程截图最有用。

对我们：三类视频都选**自制**（自研图表 + 原创解说 + Pexels/CC/官方素材二创），简介写清素材来源；绝不把 YouTube 成片不加改就当“转载”搬回来。

### 4.5 境外素材 / YouTube 同款限制

- 允许同成片双平台发，但两边版权系统独立：YouTube Content ID 过了 ≠ B 站无事；B 站有查重 + 权利人投诉（影视/音乐/赛事最严）。
- 安全栈（沿用 `docs/daily-news-video-design.md §5`）：美国联邦 PD（17 USC §105，白宫/国会/美联储/SEC/NASA 职务作品）、央行/公司官方回放与 press kit、Pexels/Pixabay（商用可、禁单卖原图/代言冒充）、Wikimedia CC-BY/SA/PD（按页署名）、YouTube CC-BY（署名 + 警惕片内插曲）。
- 禁用：影视/综艺/体育/演唱会/MV/纪录片正片、他人成片（无 CC）、GNews/NewsAPI 配图原样铺满（第三方版权归原主）、去水印/破解 DRM。
- 每段素材落 `material_attribution.json` + 简介【素材与授权】段，缺一不可。

### 4.6 AI 生成配音/内容是否需要标注

**【官方明确规定】是，必须标注。**

- 《人工智能生成合成内容标识办法》（四部门，2025-03-07 发，2025-09-01 施行，https://www.gov.cn/zhengce/zhengceku/202503/content_7014286.htm）+ 国标 GB45438：AI 文本/音频/图片/视频/虚拟场景要加**显式标识**（可感知）+**隐式标识**（文件元数据 `AIGC` 字段）。用户发布 AI 内容须**主动声明**并用平台标识功能；不得删改伪造标识。
- B 站已上线：投稿 →【创作声明】→勾选“**该视频使用人工智能合成技术**”，未声明的按社区规则追加标识（https://news.qq.com/rain/a/20250901A07LL000）。
- 我们全链路 AI（LLM 脚本 + Edge-TTS 配音）**每集必勾**，简介建议再加一句 `本视频文案/配音由 AI 辅助生成，已按平台规范声明。`

### 4.7 审核时长、常见退回、限流

- 审核：机器（拆帧 OCR/语音转文本/画面识别）+ 人工，**所有内容过人审**。时长 **【社区经验】**短视频 1–2h、长视频 2–6h、平均约 20–30 分钟；10–22 点快，深夜慢；敏感/版权可数天；被锁多在 15 分钟内速回。创作中心有“极速/畅通/正常/轻微积压/拥挤/阻塞”排队提示。
- 常见退回：分区错、标题党/封面违规、版权音乐/影视、转载冒自制、撞车、无资质财经/医学/法律冒充专家、时政无资质、低质（<1080p、音画不同步、黑边、证件号/微信号未打码）。
- 限流（【社区经验】）：推荐占比 <20%、粉丝占比过高未破圈、评论区失管连坐、设备 IP 污染、无效播放。整改后 3–7 天恢复；红线（涉政/色情/恶意对立）申诉极难。

## 5. 现有三类视频逐一判断

### 5.1 「什么指标不赚钱」回测系列 → ✅ 适合发，首发 B 站

- 分区：**知识-财经商业 `207`**（备选科学科普 `201`）。类型：**自制**。标签示例：`MACD, 量化, 投资者教育, 趋势跟踪, 震荡市`。
- 为什么适合：自研图表 + 原创解说 + 数字原样校验，独创性强；讲“为什么不赚钱”是风险教育，天然合规。
- 必须改（3 处）：
  1. 口播/简介加免责（见 §4.1 模板），标题禁“稳赚/必胜/翻倍”，保留“控制仓位/只做趋势”。
  2. 封面：用 `cover_presenter.png`（已有笔名），去黑边/边框，确保 16:9。
  3. 投稿勾 AI 声明；简介贴图表数据来源 + `key_point` 数字出处；保留 `script_review.md` 备申诉。
- 风险：低。唯一退回点可能是“信息不准确”，靠数字校验 + 来源可追溯解决。

### 5.2 书摘系列 → ✅✅ 最适合发，起量靠它

- 分区：**知识-人文历史 `228`**（校园学习 `208` 备选）。类型：**自制**（讲书二创）。
- 为什么最适合：无荐股、无时政、无版权原片，平台鼓励知识区二创。
- 必须改（3 处）：
  1. 简介写 `书名 + 作者 + 出版社 + 本视频为原创解读，非原书朗读`，避免整章朗读（合理引用：观点转述 + ≤2 数字/段）。
  2. 开头保留 `大家好，我是躺平的老黄。` + 封面署名，人设统一。
  3. 勾 AI 声明（文案/配音 AI 辅助）。
- 风险：极低。注意别用影视原声做 BGM，别在封面放二维码/联系方式。

### 5.3 每日财经/政治/科技新闻 → ⚠️ 拆开看：财经限条件可发，科技可发，政治不发

- **财经新闻（宏观/央行/财报，无个股）→ ⚠️ 限条件可发**：分区资讯-财经或知识 `207`；只讲已发生事实 + 官方来源链接；删个股代码/买卖点/涨跌预测；加免责 + `事实截至 XX 时间`；无强相关官方视频就转数据卡，不要硬凑 Pexels 空镜。
- **科技新闻 → ✅ 可发**：分区科技 `188` 系或资讯-科技；用官方 keynote/IR + press kit 图，署名；禁新闻台片段原样引用。
- **政治/时政新闻 → ❌ 建议不发**：个人无新闻许可，B 站退回/限流重灾区。若非要试：只转述新华社/央视已发 + 注明来源 + 多方说法 + 不预测不站队 + 接受被退；做好“发 10 退 9”的心理预期。

## 6. 和 YouTube 同步发布的建议

- **同一成片能复用**：容器/编码统一 `MP4 H.264 + AAC 48kHz`，1080p 6–8Mbps，两边通吃。我们已有中英双语链（`en-US-AriaNeural`）更可直接发英文版到 YouTube。
- 必须做的平台差异化：

| 项 | YouTube | B 站 |
|---|---|---|
| 标题 | 英文 hook + 关键词 + 系列名，可长 | 6–30 字中文，关键词前置，禁震惊体；短时间不重复 |
| 封面 | 1280x720 | **1920x1080（或 1146x717）**，禁边框/黑屏；中心安全区重排 |
| 简介 | 长描述 + 章节 + 外链 + playlist | 首行纯文字 + 来源 + 免责 + AI 声明 + 素材授权（API 路径限 250 字，注意截断） |
| 标签/分区 | tags + playlist（财经/政治/科技三列表） | `tid`（207/228/188 系/资讯）+ ≤10 标签；错分区直接限流 |
| 字幕 | 可传 SRT + 多音轨 | 烧录 ASS 大字（landscape ≤26 字），单行不重叠图表 |
| 时长 | 可 10 分钟+ | 6–8 分钟完播最稳，不要为凑数拆 3 集（判低质/reused） |
| 发布时间 | `unlisted` + `publishAt` 定时 | 预留 **2–6h 审核**，10–22 点投；B 站无 YouTube 式定时公开 API（biliup 只有延后 2h–15 天），排期分开算 |
| 版权/音乐 | Content ID | 查重 + 投诉制，同一 BGM 两边都要有授权 |

- 切忌：同一文案同一分钟机器人群发、关联小号重复投、只改标题复投（B 站“垃圾内容”永封条款）。

## 7. 需要用户亲自做的事情清单

1. 账号：完成**手机绑定 + 实名认证 + 答题转正（≥60 分到 Lv1）**，养到 Lv2+ 再批量发；定笔名 `躺平的老黄` + 头像 + 简介（别写“基金经理/投顾”，写了就得职业认证）。
2. 定位：定首发分区（回测 `207`、书摘 `228`），资讯-财经/科技是否做、**政治是否放弃**（建议放弃）。
3. 资质：无金融牌照=接受“只做投资者教育、不荐股”；若要发强专业内容，去做证券/基金从业或 CFA 并完成 B 站金融资质认证（否则会被限流/下线）。
4. 授权：B 站登录态只能用户亲自扫码/短信登录生成 `cookies.json`（`biliup login/renew`），**本轮未碰**；以后也不要给密码，定期 `renew`，取消授权随时在 B 站设置里操作。
5. 官方 API（可选，v2 再议）：若要走官方开放平台，需准备**企业营业执照 + 公章 + 承诺函 + 2–3 天审核 + 运营 `biz_code` 报备**；个人此路不通，先不用纠结。
6. 每集终审（5 分钟）：标题/封面/简介免责/AI 声明/分区/`tid`/自制勾选，政治类多加一道“不发”确认。
7. 运维：评论区每天看一次（违规评论不清理会连累限流），被退回 15 天内申诉（留工程截图/`script_review.md`）。
